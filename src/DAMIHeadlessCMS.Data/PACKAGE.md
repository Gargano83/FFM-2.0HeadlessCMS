# DAMIHeadlessCMS.Data

`CmsDbContext` (schema `cms`), configurazioni Fluent API, migrazioni EF
Core, Identity dedicato (`CmsUser`/`CmsRole`) ed extension method
`AddDAMIHeadlessCMSData` / `AddDAMIHeadlessCMSIdentity` del CMS headless
**DAMIHeadlessCMS**.

Fa parte della suite DAMIHeadlessCMS insieme a `DAMIHeadlessCMS.Core`,
`DAMIHeadlessCMS.Scaffolding` e `DAMIHeadlessCMS.Admin`. Per la
documentazione completa, l'architettura e la guida all'integrazione in
un'applicazione host, vedi il README del repository.
