# DAMIHeadlessCMS.Admin

Razor Class Library che contiene l'intero backoffice del CMS headless
**DAMIHeadlessCMS**: controller, view, wizard di scaffolding, CRUD
generico metadata-driven, gestione utenti/menu/pagine/localizzazioni.
Si monta in un'app host ASP.NET Core MVC tramite routing standard,
risponde di default sotto il prefisso `/dami`.

Fa parte della suite DAMIHeadlessCMS insieme a `DAMIHeadlessCMS.Core`,
`DAMIHeadlessCMS.Data` e `DAMIHeadlessCMS.Scaffolding`. Per la
documentazione completa (incluso l'esempio minimale di integrazione in
`Program.cs`), vedi il README del repository.
